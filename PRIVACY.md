# Política de privacidad de Forja

_Última actualización: 8 de noviembre de 2026_

Forja es una app gratuita para registrar entrenamientos. Esta política explica qué datos usa y para qué.

## Datos que guarda Forja

- Tus entrenamientos, rutinas, ejercicios y medidas corporales se guardan **solo en tu iPhone**.
- Forja no tiene servidores propios, no muestra anuncios y no usa herramientas de análisis ni de seguimiento.

## Inicio de sesión con Google (opcional)

Si decides vincular tu cuenta de Google, Forja solicita estos permisos:

- **Tu correo electrónico** (`openid`, `email`): solo para mostrar con qué cuenta has iniciado sesión.
- **Carpeta de datos de la app en Google Drive** (`drive.appdata`): para guardar y recuperar tu copia de seguridad (`forja-backup.json`). Esta carpeta es privada, está oculta y solo Forja puede acceder a ella. Forja **no** puede ver ni modificar el resto de tus archivos de Drive.

Los datos van directamente de tu iPhone a tu cuenta de Google. Nadie más, incluido el desarrollador de Forja, tiene acceso a ellos.

Puedes cerrar sesión en cualquier momento desde **Perfil → Cuenta de Google**, y retirar el acceso en <https://myaccount.google.com/permissions>.

## Uso de los datos de Google

El uso que hace Forja de la información recibida de las API de Google cumple la [Política de datos de usuario de los servicios de API de Google](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de uso limitado. Los datos no se venden, no se comparten con terceros y no se usan para publicidad.

## Borrar tus datos

- En el iPhone: **Perfil → Borrar todos los datos**, o elimina la app.
- En Google Drive: cierra sesión y retira el acceso en tu cuenta de Google. Así se elimina la carpeta de datos de la app.
